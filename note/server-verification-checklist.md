# 独立插件实机验证清单

> 静态审查（r1–r20，18 处修复，全 ~40 Java 文件直接覆盖、全量 build 通过）已完成。
> 本清单列出**需在真实服务端**核验的项（本环境无法运行 Paper + Slimefun4.1）。
> 环境：Paper **1.21.11** + 本地修改版 **Slimefun4.1** + **美食家(Gastronomicon)** + **异域花园(ExoticGarden)**（+ 可选 农耕工艺/无尽贪婪）。

## 0. 启动期（最高优先）
- [ ] 控制台无 `SEVERE`/堆栈；`尘世百味 加载成功`。
- [ ] 各 loader 计数行非 0：`groups/recipe_types/items(~3094)/foods(189)/mob_drops(106)/machines(142)/...`。
- [ ] 无「资源缺失」警告（13 内容 YAML + data/*.yml 均应加载）。
- [ ] 加载耗时合理（info.yml 称 1~3 分钟）。

## 1. r17 关键修复：168 饮品可食性 ⚠️ 重点
- [ ] 取一个饮品（如 `WT_JIANGZHI` 姜汁，script=gz2），右键**可正常进食**（进食动画+消耗 1 个）。
- [ ] 进食后饥饿/饱和按 gz2(food=6/saturation=6) 恢复。
- [ ] **若不可食**（0 营养 FoodComponent 在当前 Paper 不被认可）：回退为「默认营养 1」方案（FoodHelper 中 `nutrition<=0` 时 nutrition 设 1 而非 0）。
- [ ] 对照：烤肉（`WT_KAOMAOROU` 等，script=rou，nutrition=5）仍正常可食、恢复正常。

## 2. 数据操作 / 复制漏洞回归（r1–r12 修复）
- [ ] **钓鱼**：百味钓竿 + 5 鱼饵各试一次，掉落按权重、消耗 1 鱼饵；**鱼饵耗尽后副手清空、不会无限钓**（r1 幽灵物品修复）。
- [ ] **消耗品**：香烟(yan，副手打火石)消耗 1 打火石、到 0 清空不无限点烟；xuejia(副手剪刀) 同理（r8）。
- [ ] **drop_from 双重掉落**（r12）：种一棵成熟为 `SWEET_BERRY_BUSH` 的 WorldTaste 作物并破坏 → **仅掉作物产物**，**不再额外掉** `WT_NGSCZZ1/2`（破坏自然甜浆果灌木才掉）。
- [ ] **作物加权掉落**（r11）：多种几棵，统计收获量符合权重分布。
- [ ] **工作台**（如百味万用炉）：空点击不扣能量；没电时不吞输入；输出放不下提示（r1/r5）。
- [ ] **机器**：电力配方机/多方块机 正常合成、消耗输入、产出；重启机器丢失在合成中的输入（等同上游 AContainer，已知）。

## 3. 级联故障隔离（r4/r16 修复）
- [ ] （可选）临时在某 yml 注入一条畸形条目，确认**仅该条跳过**、其余内容正常加载、不致插件空载。

## 4. 已知差距 / 内容缺口（非代码 bug）
- [ ] 指南中 `WT_XIANGYUNCF`、`WT_XUECHENGGQ` 相关配方显示为石头（未定义 id，需内容作者补）。
- [ ] button 型物品组点击会多一个空分页（已知小差距，可后续对齐）。

## 5. 高负载稳定性（用户核心诉求）
- [ ] 大量机器同时 tick（数十台电力机满载）下 TPS 正常（空闲早返回已优化 r5）。
- [ ] 大量作物方块（数百）生长/收获无明显卡顿。
- [ ] 刷怪塔高频死亡下 mob_drops 掉落正常、无延迟尖峰（按实体类型索引 O(该类型) r5）。
- [ ] 多玩家同时钓鱼/进食无异常。

## 6. 不信任用户输入（对抗修改版客户端）
- [ ] 用修改版客户端尝试：伪造手持物品右键消耗品/钓竿 → 服务端按真实背包判定（不生效）。
- [ ] 尝试对机器塞入 NBT 篡改物品 → 匹配按 SF id/材质，不被欺骗。
- [ ] 快速连点工作台/消耗品 → 不出现复制或吞物品（主线程同步、每次重校验）。
