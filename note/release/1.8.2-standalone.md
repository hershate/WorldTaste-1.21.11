# 1.8.2-standalone

> WorldTaste 从「RSC 脚本版」改写为**独立 Slimefun4.1 插件**的首个基线。
> 设计详见 [../standalone-plugin.md](../standalone-plugin.md)。

## 版本定位

- 版本：`1.8.2-standalone`（[plugin/build.gradle.kts](../../plugin/build.gradle.kts)、[plugin.yml](../../plugin/src/main/resources/plugin.yml)）
- 内容来源：与脚本版 WorldTaste 1.8.2 完全相同的 YAML（items/machines/...），打包进 jar。
- 运行依赖：`Slimefun`（本地修改版 Slimefun4.1）+ 软依赖 Gastronomicon/ExoticGarden/Cultivation/InfinityExpansion。**不再依赖 RykenSlimefunCustomizer**。

## 主要改动（相对脚本版）

### 新增：独立插件工程（plugin/）
- Gradle 工程，`compileOnly` 本地 `SlimeFun4.1-4.9.5.jar` + Paper 1.21.11；产出 `WorldTaste-1.8.2-standalone.jar`。
- 主类 `WorldTastePlugin`（`JavaPlugin + SlimefunAddon`），启动期读取打包的 YAML 注册全部内容。

### 内容加载（load/，对齐 RSC Reader 但精简）
- groups（nested/sub/button/seasonal）、recipe_types、items、foods、mob_drops、menus、geo。
- 机器：`WTRecipeMachine`(AContainer, 支持 chance/chooseOne/noConsume)、`WTMultiBlockMachine`、模板/关联/工作台统一走配方机器路径。

### 脚本行为移植为 Java（behavior/ + items/）
- 消耗品：`ConsumableItem`，66 个脚本（含 yl/tang/jiu/yan/zhongdu 等独立脚本的药水/空气/冻结/打火石等效果）。
- 作物：`CropBlock`(BlockTicker)，121 个。
- 钓鱼：`FishingListener`(PlayerFishEvent)，百味钓竿 + 5 鱼饵 + 133 掉落。
- 生物掉落：`MobDropListener`(EntityDeathEvent)，106 种。

### 行为参数数据
- `plugin/src/main/resources/data/*.yml`（consumables/crops/fishing）：**手工维护**（不再使用转换脚本），运行期由 Java 行为类读取。

## 已知差距（详见 [../standalone-plugin.md#已知差距](../standalone-plugin.md)）

foods 自定义 nutrition/onEat、workbench 点击合成、GEO 真实注册、作物破坏掉落去重、少数未解析独立脚本、运行期实机验证。

## 构建

```
cd plugin
./gradlew build        # 产出 build/libs/WorldTaste-1.8.2-standalone.jar
```

> 行为参数数据（`data/*.yml`）为手工维护，无需生成步骤。
